# v0.3.0-alpha.1 release checklist

Release date: 2026-10-14

## Publication boundary

- [x] The HACS artifact is `dist/dynamic-energy-dashboard.js`.
- [x] The stable `dynamic-energy-shadow-card` remains observation-only.
- [x] The alpha control card is a separate custom element.
- [x] No private entity mappings, captures, credentials or local configuration
  are included.
- [x] `PROJECT.local.md` remains ignored and is not part of the release.

## Safety contract

- [x] Only `OFF` and `ARMED_BLOCKED` are available.
- [x] `LIVE` is not available.
- [x] Generated automations set `execution_allowed: false`.
- [x] Generated automations stop before an actuator action.
- [x] Automation IDs are limited to `dynamic_energy_battery_v1` and `dynamic_energy_ev_v1`.
- [x] Foreign, modified and ambiguously mapped automations fail closed.
- [x] Generated operational configuration is sealed with an exact canonical
  snapshot; ordinary later changes, description changes and unexpected returned
  IDs invalidate ownership verification.
- [x] Home Assistant writes require an explicit user confirmation.
- [x] No SMA, Smappee, battery, EV-charger or MQTT actuator write is implemented.

separate acceptance step. Publication of this alpha does not authorize physical
control or actuator writes.
