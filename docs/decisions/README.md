# Decision logs

Belangrijke besluiten worden opgeslagen als `ADR-NNN-korte-titel.md` met:

- Status: proposed, accepted, superseded of rejected
- Datum
- Context en bewijs
- Besluit
- Alternatieven
- Gevolgen en risico's
- Gerelateerde tickets

Fase 1 legt alleen voorgestelde besluiten vast. Keuzes die productiegedrag beïnvloeden vereisen eigenaarvalidatie en een apart uitvoeringsticket.
